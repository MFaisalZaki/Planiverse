# Renders

Contact sheets and animations of planner traces.

Files ending `_gb` are captured from commercial cartridges under emulation and
contain those titles' original graphics. They are **not** covered by this
repository's GPL-3.0 licence — see [THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md).

All other files in this directory are rendered from this repository's own
reimplementations and are covered by the project licence.
